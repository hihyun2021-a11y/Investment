## 1. 합의된 3종 조건 (매도인 보고자료 p.3 기준)
| 구간 | 기간 | 3종 권리 |
|---|---|---|
| 인수 | '26.10 거래종결 | 매도인 PFV가 100억 인수(2,600억 현금 + 100억 3종), 무배당·무의결권 |
| 감자 기한 | 발행일 + 2년 2개월('28.12) | 리파이낸싱 재원 유상감자로 100억(발행가액) 회수 |
| 미이행 1단계 | 이후 1년('29.12까지) | **연 6%** 누적적 배당 |
| 미이행 2단계 | 이후 1년('30.12까지) | **연 8%** 누적적 배당 |
| 미이행 3단계 | 발행일 + 4년 2개월('30.12) | **부동산 매각청구권** (보고자료상 3종 원본 회수 매각가 2,841억, Cap 5.53%) |

- 인수 주체: 보고자료는 **매도인 PFV**(LF 아님). 인수 방식은 ① 현금 납입 또는 ② 매매대금채권 100억 출자전환(상계) 검토 중.
- 세무(성지)·법률(세종) 검토 결론: 매각 사업연도까지 PFV 요건 충족, 취득세 중과배제 추징·사업이익 법인세 리스크 없음, 3종 수익에는 법인세 가능.

## 2. 워터폴 원칙 (사용자 지시)
**1종 배당 → 2종 배당 → 1종 원본 → 2종 원본 → 3종 배당** — 3종의 부활 배당(6%/8%)이 1·2종의 배당과 원본 회수보다 앞서지 않도록 한다.

## 3. 정관 제11조 개정안 골격
### ② 평상시 결산기
1. 1종 누적 미배당액 → 2. 1종 당기(연 7.0%)
3. 2종 누적 미배당액 → 4. 2종 당기(연 7.5%)
5. **3종 누적 미배당액(가산배당기간 발생분)** → 6. **3종 당기 가산배당(연 6% / 연 8%)**
7. 보통주 확정배당 미배당액 → 8. 보통주 확정배당(연 7.5%, 최초 1년) → 9. 잔여 보통주
- 평상시에는 원본 반환 단계가 없으므로 1·2종 원본과의 역전 문제는 생기지 않음. 보통주 확정배당기간(최초 1년)과 3종 가산배당기간('28.12 이후)은 겹치지 않음.

### ③ 매각 결산기 / ④ 청산
1. 1종 누적 미배당액·당기 배당
2. 2종 누적 미배당액·당기 배당
3. **1종 발행가액 상당액**
4. **2종 발행가액 상당액**
5. **3종 누적 미배당액·당기 가산배당**
6. 3종 발행가액 상당액
7. (해당 시) 보통주 확정배당 미배당액
8. 보통주 발행가액 상당액
9. 잔여: 2종 20% / 보통주 80%
- 현행 v8 ③1호는 "②1~6호를 먼저 배당"하는 구조라 3종 가산배당이 ②에 들어가면 **1·2종 원본보다 앞서게 됨 → 반드시 ③·④에서 3종 배당을 1·2종 원본 뒤로 분리**해야 함(이번 지시의 핵심).

## 4. 문언 정의 시 유의점
1. **가산배당 개시 요건**: "발행일로부터 26개월이 되는 날(응당일)까지 주주간계약 제5조에 따른 유상감자가 완료되지 아니한 경우 그 다음 날부터" 등 날짜로 특정. 감자 완료 시 가산배당 소멸·일할 정산.
2. **기간 표기 불일치 확인**: 사용자 메시지는 "1년간 6%, **2년간** 8%", 보고자료는 "1년간 6%, **이후 1년간** 8%(매각청구권 4년 2개월)". 2년간이면 매각청구권 시점이 5년 2개월로 바뀜 → 확정 필요.
3. **4년 2개월 이후 배당률**: 매각청구권 행사 후 실제 매각까지 3종 배당률(8% 지속 여부) 미정.
4. **SHA 제5조와 기한 불일치**: v23은 "24개월 + 절차 지연 시 [3]개월(최대 27개월)", 보고자료는 26개월. 하나로 통일.
5. **매각청구권은 주주간계약 사항**: 정관에 주주의 자산매각 청구권을 두기 어려우므로 SHA에 규정(청구 → 이사회·주총 매각 결의 협조 의무, 1·2종·보통주 동의 구조, 대주·리파이 대주 동의 조건).
6. **무의결권 유지**: 현행 상법상 배당 미지급으로 의결권이 자동 부활하지 않음. 부활시키지 않으려면 정관 제11조 ⑤ 현행 문언 유지.
7. **보통주 배당 제한과의 관계**: 우리은행 조건표의 "중순위 DSCR 1.0x 미만 시 보통주 배당금지"는 보통주만 대상 → 3종 가산배당은 제한되지 않음. 대주가 3종도 포함하자고 할 수 있음.
