## 안건별 요약

**1. 본격 검토 진행 여부**
- 배경: 실사 4건(IM·재무DD·법률DD·모델) 접수, 감정평가서·시장실사·임대차계약 원본·인수확약서 [미접수]. 수익률 3원천 불일치(2종 9.15~9.24%, 보통주 16.18~16.44%). [`20260916_재무모델_시트구조_v01.md` §3]
- 옵션: (A) 검토 중단 (B) 조건부 검토 진행 (C) 즉시 투자 방향 확정.
- 권고: B. 투자 승인이 아닌 검토 진행만 승인. 현 단계 가역성 최고(취소 비용 = 내부 공수).
- 근거: 임대율 99.3%·Cap 4.89%·1~2년차 DSCR 1.72~1.76은 검토 가치 있음. 단 3년차 DSCR 0.89, 이해관계인 거래, 자료 미접수로 즉시 확정 불가.
- 리스크: 검토 후 불참 시 코람코와의 관계 비용(낮음). 검토 자원 6주 집중 투입.

**2. 트랜치 방향**
- 배경: 1종 240억(7.0%, IRR 7.12%, 우리투자증권 LOC, 24개월 후 공모예외기관 인수) / 2종 500억(7.5%+매각차익 20%, IRR 9.24%, 삼성증권 LOC, 12개월 후 인수) / 보통주 148억(잔여+매각차익 80%, IRR 16.44%, KLI 9월말 심의). [핵심지표 §5]
- 옵션: 1종 / 2종 / 보통주 / 복수 / 불참.
- 권고: 2종 1순위. 보통주는 Exit Cap·쿠팡 옵션 민감도 확인 후 소액 병행 여부 판단. 1종은 리파이('28.10) 이후 진입이므로 별도 트랙.
- 근거: 2종은 우선배당+매각차익 참여, 보통주 148억이 후순위. 보통주 16%는 Exit Cap=매입 Cap(4.89%)·임대료 갱신 상승·리파이 성공 3개 가정에 동시 의존.
- 리스크: 2종 50.6% 인수 시 과점주주 간주취득세(모델 `간주취득세` 시트) → finance-ir 수치 대기. 공실 12% 시 2종 IRR 6.77%(IM p.23).

**3. 인수확약서 제출 보류** — 배경: 증권사 LOC 구조상 공모예외기관 인수확약을 요구할 가능성(문서 [미접수]). 권고: 조건 충족 전 미제출. 근거: 확약 후 철회 비용·평판 영향이 가장 큰 단계. 리스크: 배정 슬롯 상실 → 안건 2와 함께 코람코에 배정 가능 트랜치·기한 즉시 확인.

**4. 외부 법무법인 검토** — 배경: 매도인 코크렙안양 주주 LF 95%·코람코 5%, LF가 3종우선주 100억 재투자, AMC도 코람코 → 부투법·법인세법·공정거래법 4개 항목(법률DD 2.7). 내부 검토는 외부 확인 필수. 권고: 즉시 의뢰. 리스크: 특별결의 필요 시 종결 지연.

**5. 전략 기준** — 배경: `shared/strategy.md` 전 항목 공란. 권고: 최소 목표수익률·리스크 성향·단일 임차인 한도 3개 우선 확정. 미확정 시 본 딜 정합성 판정 "기준 미설정"으로 남음.
