# RFIS 마케팅 캘린더 자동 입력

구글 캘린더 **"마케팅 캘린더"** 일정을 읽어 RFIS(`rfis.koramco.com/marketing/marketing-calendar`)의
**[계획 등록] · [결과 등록]** 에 자동으로 입력합니다. 입력 전에 **승인 창**에서 내용을 확인·수정하고,
승인한 건만 입력하고 **저장 버튼까지 자동으로 누릅니다**(저장 직전 건마다 확인하려면 `config.json`의 `confirm_each`를 `true`로).

## 1. 구글 캘린더 준비 (한 번)
1. 구글 캘린더 → 왼쪽 "다른 캘린더 +" → **새 캘린더 만들기** → 이름 `마케팅 캘린더`.
   - 주소는 반드시 **마케팅 캘린더의** 설정에서 복사하세요(기본 개인 캘린더 주소를 넣으면 개인 일정까지 읽힙니다).
2. 그 캘린더 설정 → **캘린더 통합 → "iCal 형식의 비공개 주소"** 복사.
3. 이 폴더의 `settings.txt`(처음 실행 때 자동 생성, 메뉴 5번)에 `ICS_URL=복사한주소` 저장.
   - 비공개 주소는 비밀번호처럼 다루세요. 깃에 올라가지 않습니다.

## 2. 일정 쓰는 법
| 칸 | 형식 | 예 |
|---|---|---|
| 제목 | `[마케팅구분] 고객명 / 마케팅목적` | `[F.I/LP/대주/증권] 삼성증권(주) / 시장 동향 전달` |
| 날짜 | 미팅 날짜 | 월·주차는 자동 계산 |
| 메모 | 줄마다 `항목: 내용` | `주요내용: …` / `코멘트: …` / `고객담당자: 이주연 / 실물부동산팀 / 팀장급` / `당사담당자: 안용현, 임영규` |

- 마케팅구분: `F.I/LP/대주/증권`, `S.I/시행/시공/매도`, `Tenant`, `Agent/기타` (줄임말 `FI`, `SI`, `Agent`도 인식)
- 마케팅목적: RFIS 목적 버튼 이름 그대로(예: `시장 동향 전달`). 여러 묶음에 같은 이름이 있으면 `프로젝트 운용-특이사항 보고`처럼 묶음까지.
  - 버튼 이름이 아니면(예: `안양물류센터 VAT 대출 협의`) 낱말로 추정합니다(`대출`→대주 참여 제안 등, `config.json`의 `purpose_keywords`). 메모에 `목적: 대주 참여 제안` 줄을 쓰면 그것이 우선합니다.
- 메모 줄 앞의 체크박스(☐)·글머리(-, •)·굵게 같은 서식은 자동으로 무시합니다(스티키메모 동기화 메모도 그대로 인식).
- 고객명은 정확하지 않아도 됩니다. `삼성증권`만 써도 RFIS 고객정보에서 `삼성증권(주)`를 찾아 고릅니다((주)·주식회사·띄어쓰기 무시, 부분 일치).
  - `한투증권`, `NH증권`, `신금투` 같은 줄임말은 `config.json`의 `customer_alias`로 바꿔 검색합니다(추가 가능).
  - 후보가 여러 개면(예: `삼성` → 삼성증권·삼성생명) 창에서 번호로 고르게 하고, 고른 이름은 `data/고객명_별칭.json`에 기억해 다음부터 자동 적용합니다.
- 당사담당자를 안 쓰면 `config.json`의 `default_staff`(안용현)가 들어갑니다.
- `고객담당자`(이름 / 부서명 / 직급)는 RFIS "고객사별 담당자 등록" 팝업에 들어갑니다. **부서명·직급은 필수**, 직급은 `임원급`·`팀장급`·`팀원급`.
  - 메모에 없으면 예전에 그 고객으로 등록한 담당자 정보(메뉴 7번으로 RFIS 엑셀에서 가져오거나, 한 번 등록하면 자동 저장)를 씁니다.

## 3. 주차 계산
RFIS 마케팅 결과 330건을 대조한 결과, **월~일 한 주를 그 주 목요일이 속한 달의 주차**로 매기고 있습니다(329건 일치).
예: 9/28(월)~10/4(일) = 10월 1주차, 10/26~11/1 = 10월 5주차. 1~7일 방식으로 바꾸려면 `config.json`의 `week_rule`을 `day7`로.

## 4. 실행
`run_rfis.bat` 더블클릭 → 메뉴
1. **미리보기** — 캘린더를 읽어 계획·결과 입력안을 보여 줌(RFIS 접속 안 함)
2. **계획 등록** — 이번 달~45일 안 일정을 월·구분별로 묶어 주차별 고객명 입력
3. **결과 등록** — 최근 30일 지난 일정 중 미등록 건 입력(주요내용·코멘트 필요)
4. **RFIS 화면 구조 저장** — 처음 한 번 실행. 등록 창·드롭다운 구조를 `data/diag_*` 로 저장 → Claude에게 보내면 입력 정확도를 맞춤
5. 설정 파일 열기 · 6. 등록 이력(`data/등록이력.csv`) 열기
8. **RFIS 로그인 정보 저장** — 아이디·비밀번호를 한 번 입력하면 Windows 자격 증명 관리자에 암호화해 보관, 이후 로그인 화면이 나오면 자동 입력(비밀번호는 파일·코드에 남기지 않음)
7. **고객담당자 사전 만들기** — RFIS `마케팅 결과 관리` → [엑셀 다운로드] 파일을 이 폴더에 넣고 실행하면 고객별 최근 담당자·부서·직급을 저장

### 결과 등록 자동 입력 순서 (RFIS 화면 기준)
고객 선택 팝업(검색 → 조회 → 체크 → 선택 완료) → 고객사별 담당자 등록(담당자명·부서명·직급 → 담당자 등록 완료) → 완료일 키인 → 완료주차·마케팅구분 드롭다운 → 마케팅 목적 버튼 → (프로젝트·대상자산 칸이 생기면 제목·메모와 글자가 가장 많이 겹치는 항목 선택, 메모 `프로젝트: 안양물류`로 지정 가능) → 당사담당자 → 주요 내용·코멘트 → (확인 후) 저장

- 첫 실행 때 가상환경과 Playwright를 자동 설치합니다(1~2분). **Python 3.11~3.13** 필요(3.14 이상은 아직 설치 불가 → `py install 3.13`).
- 크롬은 PC에 설치된 것을 씁니다. 처음 한 번 열린 크롬에서 RFIS에 로그인하면 다음부터 유지됩니다(`data/chrome-profile`). 아이디·비밀번호는 저장하지 않습니다.
- 등록한 일정은 `data/state.json`에 기록해 다시 올리지 않습니다.

## 5. 유의사항
- 사내 시스템 자동 입력은 IT·보안 규정을 확인한 뒤 사용하세요.
- 오류가 나면 해당 건은 건너뛰고 `data/diag_오류_*.html/png`가 저장됩니다. 그 파일을 보내 주시면 고칩니다.
- 같은 월·구분의 계획을 두 번 등록하면 카드가 중복될 수 있어, 이미 등록된 월·구분은 승인 창에서 기본 해제됩니다.
