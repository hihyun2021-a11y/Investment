# 신규투자 워크벤치 (로컬 웹앱)

신규투자 업무 11단계를 한 화면에서 처리하는 로컬 프로그램입니다. 샘플 서류를 올리면 **Claude API**가 그 양식을 따라 새 문서를 작성합니다. 안양물류센터(ANYANG-LOGIS)에서 만든 공문·기안문·계약서·일정·Q&A·RFP·렌트롤과 `shared/강의자료/표준서식_Clean`이 기본 샘플로 연결돼 있습니다.

## 1. 처음 실행 (1단계: 내 PC에서만)

준비물: Python 3.10 이상, Anthropic API 키(console.anthropic.com → API Keys)

**Windows**
1. 이 폴더(`platform/webapp`)의 `run.bat`을 더블클릭합니다.
2. 처음 실행하면 `.env` 파일이 메모장으로 열립니다. `ANTHROPIC_API_KEY=` 뒤에 키를 붙여넣고 저장한 뒤 `run.bat`을 다시 실행합니다.
3. 브라우저에서 http://127.0.0.1:8765 이 열립니다.

**Mac·Linux**
```bash
cd platform/webapp
./run.sh          # 처음에는 .env 를 만들고 멈춤 → .env 에 키 입력 후 다시 실행
```

처음 실행할 때 `.venv` 가상환경을 만들고 필요한 패키지를 설치합니다(1~2분). 그다음부터는 바로 켜집니다.

## 2. 화면 구성

| 메뉴 | 전용 기능 | 만들 수 있는 문서(샘플 양식 기반) |
|---|---|---|
| 홈 | 프로젝트 목록(`projects/*/PROJECT.md`), 다가오는 일정, 최근 결과 | — |
| Sourcing | 딜 파이프라인 표 + **지도**(지도 클릭으로 좌표 입력, 마커에서 구글지도 열기) | 딜 스크리닝 메모, 자문사 마케팅 현황 정리 |
| 시장조사 | 웹 검색으로 최신 자료 찾기(선택) | 인덱스별 시장조사 보고서, 재무모델 가정 |
| 구조화 | — | Asset·Share·재투자·현물출자·유동화·OpCo-PropCo 비교 및 근거법규 |
| 자료작성 | — | TM, IM, MOU, 공문, 결재문(기안), 영업인가 서류 |
| 계약서작성 | — | 매매, 임대차, 주주간계약, 위탁 3종, 정관, 대출약정·인수확약서 |
| 일정관리 | **월간 캘린더**, 일정 표, 휴대폰·아웃룩용 `.ics` 내보내기 | 마스터 일정표(역산), 이메일 요약·우선순위, 회의록 |
| 기관별 투자심의 | 기관별 Q&A 표 | Q&A 대응 요약(표가 자동으로 함께 들어감), 개별 답변 초안 |
| 발주관리 | RFP 목록·업체별 견적 표 | RFP, 견적 비교표·품의문(견적 표가 자동으로 함께 들어감) |
| 등기접수 | — | 등기 유형별 서류 체크리스트·접수 순서 |
| PMI | — | 렌트롤, 자산운용보고서, 임대안내서 |
| 배포 | **이메일 양식**(`{{변수}}`) 저장 → CSV로 일괄 채우기 → 메일 앱 열기·`.eml` 내려받기 | 기존 메일로 새 양식 만들기 |
| 결과 보관함 | 지금까지 만든 결과 다시 보기·편집·Word 다운로드 | — |

### 문서 생성 순서 (모든 메뉴 공통)
1. **만들 문서**를 고릅니다.
2. 입력칸을 채웁니다. 모르는 값은 비워 두면 결과에 `[  ]`·`[확인 필요]`로 표시됩니다.
3. **참고 샘플**에서 따라 할 서류를 체크합니다. 새 샘플(PDF·Word·PPT·Excel·이메일)은 바로 올릴 수 있고, '라이브러리에 저장'을 켜 두면 다음에도 목록에 나옵니다.
4. **생성하기**를 누르면 결과가 실시간으로 나타납니다. 복사, 편집, Word·Markdown 다운로드가 가능합니다.

스캔 PDF처럼 글자를 뽑을 수 없는 파일은 PDF 원본을 그대로 Claude에 보내 읽게 합니다(30MB 이하).

## 3. 설정 (`.env`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | 필수. 코드·깃에 넣지 말고 `.env`에만 둡니다(`.gitignore` 처리됨) |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 사용할 모델 |
| `CLAUDE_EFFORT` | `high` | 사고 강도. 빠른 초안은 `medium`, 계약서처럼 정확도가 중요하면 `xhigh` |
| `APP_HOST` / `APP_PORT` | `127.0.0.1` / `8765` | 로컬 전용 주소 |
| `APP_PASSWORD` | (비움) | 설정하면 접속할 때 비밀번호를 묻습니다(아이디는 아무거나) |
| `GOOGLE_MAPS_API_KEY` | (비움) | 선택. 없어도 OpenStreetMap 지도와 '구글지도에서 열기' 링크는 동작 |

## 4. 데이터 보관 위치

- `platform/webapp/data/app.db` — 딜·일정·Q&A·발주·이메일 양식·생성 결과 (SQLite)
- `platform/webapp/data/samples/` — 내가 올린 샘플
- `data/` 폴더는 깃에 올라가지 않습니다. 백업하려면 이 폴더를 복사해 두세요.
- 첫 실행 때 안양물류센터 예시 데이터(딜 1건, TIMELINE.md 일정, 대주 Q&A 3건, RFP 1건, 이메일 양식 3종)가 들어갑니다. 지우고 새로 시작하려면 `data/app.db`를 삭제하면 됩니다.

## 5. 2단계: 휴대폰·외부 기기에서 접속 (시운전 후)

로컬에서 충분히 써 본 뒤 진행하세요. **인터넷에 그대로 열지 마세요.** 계약서·딜 정보가 들어 있습니다.

권장 방법은 **Tailscale**(개인 사설망)입니다.
1. PC와 휴대폰에 Tailscale 앱을 설치하고 같은 계정으로 로그인합니다.
2. `.env`에서 `APP_HOST=0.0.0.0`, `APP_PASSWORD=긴비밀번호` 로 바꾸고 다시 실행합니다.
3. 휴대폰 브라우저에서 `http://<PC의 Tailscale 이름 또는 100.x.x.x>:8765` 로 접속합니다.

대안: Cloudflare Tunnel + Cloudflare Access(회사 이메일 인증)로 공개 주소를 만들 수 있습니다. 어느 방법이든 회사 보안 정책(외부 반출·클라우드 사용 규정)을 먼저 확인하세요.

## 6. 유의사항

- 생성할 때 체크한 샘플과 입력 내용이 Anthropic API로 전송됩니다. 대외비 자료는 회사 정책에 맞는지 확인하고 사용하세요.
- 결과물은 **초안**입니다. 수치·조항은 원본과 대조하고, 법률·세무 판단은 외부 법무법인·회계법인 확인을 거치세요.
- 안전 정책으로 요청이 거절되면 서버가 자동으로 다른 모델로 다시 시도합니다(`fallbacks: "default"`).
- 이메일 자동 수신(Gmail·아웃룩 연동)은 아직 없습니다. 지금은 메일 본문을 붙여넣거나 `.eml`을 올려 요약합니다.

## 7. 파일 구조

```
platform/webapp/
  run.bat / run.sh        실행 스크립트
  requirements.txt        패키지 목록
  .env.example            설정 예시
  app/main.py             웹 서버(API)
  app/modules.py          메뉴·문서 종류·기본 샘플 연결 ← 새 문서 종류는 여기에 추가
  app/claude.py           Claude API 호출(작성 원칙 system 프롬프트 포함)
  app/extract.py          샘플 텍스트 추출(PDF·Word·PPT·Excel·이메일)
  app/exporter.py         결과 → Word 변환
  app/db.py               로컬 DB와 안양 예시 데이터
  static/                 화면(HTML·CSS·JS)
```
