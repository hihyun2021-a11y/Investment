# 08_매매_임대차계약서 (담당: legal-counsel)

매매·임대차 관련 **계약 원본**을 모아 두는 곳이다. 원본은 수정하지 않는다. 검토 의견·쟁점 정리는 `02_실사보고서/법률/`에 별도 파일로 만든다.

| 하위 폴더 | 내용 |
|---|---|
| `매매계약/` | 부동산매매계약서(SPA), 양해각서(MOU), 정산·승계합의서 |
| `임대차계약/` | 임차인별 임대차계약서 및 변경합의서·확약서 |
| `보증금_시설투자/` | 임대보증금 내역·권리설정 사항, 임차인 CAPEX 투자내역 |

텍스트 추출본은 `00_원본자료/text/<원본파일명>.txt`에 있다. 스캔본이라 텍스트가 없는 파일은 원본을 직접 확인해야 한다.
