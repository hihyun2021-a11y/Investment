# 00_원본자료 (담당: data-steward)

- `raw/` **신규 접수함**. 받은 파일을 그대로 넣는다. data-steward가 INDEX 등록·텍스트 추출을 마치면 해당 업무 폴더(01~08)로 옮긴다. 분류가 끝나면 이 폴더는 비어 있다.
- `text/` 원본의 텍스트 추출본 (`platform/scripts/extract_text.py`가 프로젝트 전체를 훑어 생성). 읽기 전용 캐시이며, 인용은 원본 파일명·페이지로 한다.
- `processed/` 원본에서 추출·표준화한 데이터 (CSV/MD). 팀의 단일 수치 원천(SSOT).
- `history/` 버전 간 비교, 시계열 추이 분석.
- `INDEX.md` 접수 원본 목록과 **현재 보관 위치** / `CHANGELOG.md` 변경 이력 / `DATA_DICTIONARY.md` 항목 정의·단위.

새 파일을 `raw/`에 넣은 뒤 "새 자료 접수 처리해줘"라고 요청하면 등록·추출·분류를 수행한다.
원본은 어느 폴더에 있든 **절대 수정하지 않는다**. 같은 자료의 새 버전은 삭제하지 말고 새 파일로 추가한다.
