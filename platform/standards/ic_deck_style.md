# 투자심의 자료 작성 양식 (사내 표준)

출처: `platform/templates/ic_deck/투자심의자료_양식_표준_v1.0_260325.pptx` (74p), `투자심의자료_양식_KLI_260824_v3.pptx` (44p)
**"투자심의 자료를 작성해달라"는 요청이 오면 이 양식으로 `.pptx`를 생성한다.** 빈 템플릿과 생성 스크립트가 준비돼 있다.

- 빈 템플릿: `platform/templates/ic_deck/투자심의_빈템플릿.pptx` (레이아웃·로고·머리말·꼬리말 유지, 슬라이드 0장)
- 생성 스크립트: `platform/scripts/ic_deck.py` (python-pptx 기반, 아래 규격이 코드로 구현돼 있음)

## 1. 판형과 여백
| 항목 | 값 |
|---|---|
| 슬라이드 크기 | **A4 가로 11.69 × 8.27 inch** (16:9 아님) |
| 본문 좌측 기준선 | 0.57" (리드 문장 0.31", 섹션 밴드 0.50") |
| 본문 우측 한계 | 11.27" (본문 폭 최대 10.70") |
| 머리말 구분선 | y = 0.96" (전폭) |
| 리드-본문 구분 바 | y = 2.05" |
| 본문 시작 | y = 2.58" |
| 꼬리말 구분선 | y = 7.44", 로고 y = 7.89" |

## 2. 서체
**KoPubWorld돋움체** 한 가족만 사용한다. Light(본문) · Medium(강조) · Bold(제목·표 머리) 세 가지. 바탕체는 표지 등 극히 일부에만 쓴다.

| 요소 | 서체 | 크기 |
|---|---|---|
| 슬라이드 제목 (`> 1. 투자자산 개요`) | Light **Bold 적용** | 11pt |
| 리드 문장 (결론) | Light | **16pt** |
| 리드 보조 문장 (`•` 불릿) | Light | **12pt** |
| 섹션 밴드 라벨 | Bold | 10pt |
| 표 머리행 | Bold | 10~11pt |
| 표 본문 | Light | 10~11pt |
| 각주·출처 (`*`, `※`) | Light | 8~10pt |
| 대제목 (표지 자산명) | Bold | 24pt |

가장 많이 쓰이는 크기는 10pt → 11pt → 12pt 순이다. 14pt 이상은 리드와 표지에만 쓴다.

## 4. 슬라이드 유형과 레이아웃
빈 템플릿에는 12개 레이아웃이 있고, **섹션 이름이 레이아웃 머리말에 내장**돼 있다. 섹션이 바뀌면 레이아웃을 바꾼다.

| 레이아웃 이름 | 머리말 | 용도 |
|---|---|---|
| `4_사용자 지정 레이아웃` | (없음) | 표지, 간지, 종료 페이지 |
| `9_흰배경` / `8_흰배경` | 투자심의위원회 개요 | 심의안건, 추진일정, 참고자료 |
| `7_흰배경` | 프로젝트 추진 배경 | 배경 설명 |
| `5_흰배경` | Investment Highlights | 투자 하이라이트 |
| `1. 투자개요` | I. 사업개요 | 자산·입지·시장·Peer 분석 |
| `2. 투자계획` | II. 투자계획 | 리츠개요·구조·재원조달·수익률·DSCR·민감도 |
| `1_3. 운영 및 Exit Plan` | III. 운영계획 | 운영가정, Value-add, Exit |
| `4. 리스크 요인분석 및 관리방안` | Ⅳ. 리스크 요인분석 및 관리방안 | 리스크 표 |
| `1_4. 리스크 요인분석 및 관리방안` | Ⅳ. 향후조치 예정사항 | 보완 예정사항 |
| `10_흰배경` / `11_흰배경` | Appendix. | 부록 |

### 표지
우상단 `< Strictly Confidential >` (y 0.70) + 로고(y 1.04) → 전폭 구분선(y 1.23) → 제목 블록(y 2.20, 좌 0.41): 부서·안건 한 줄 / **자산명** / 회의명 → 하단 영문 팀 표기(y 6.06) + 발행월(y 6.32) + 영문 배포제한 문구(y 7.07).

### 목차
회의명(y 2.27) → 가로선(y 2.40, x 2.50~11.20) → `Contents`(y 3.04) → 항목 목록(우측 x 7.89).

### 간지
전체 목차를 싣고 해당 섹션만 강조한다. 섹션이 바뀔 때마다 넣는다.

### 본문 (가장 많이 쓰는 형식)
1. **제목**: `> 1. 투자자산 개요` — `>` 를 반드시 붙이고 번호를 단다. y 0.24, 좌측 여백 1.81"(머리말 섹션명 뒤에서 시작).
2. **리드**: y 1.14. 첫 줄 16pt 결론 문장, 둘째 줄부터 12pt `•` 불릿 보조 문장 1~2개.
3. **섹션 밴드**: y 2.17, 폭 10.70", 높이 0.27", 배경 `345B86`, 10pt Bold 라벨 (예: `대상자산 개요`).
4. **본문**: y 2.58부터. 표, 이미지+표 2단(이미지 좌 4.30" / 표 우 6.17"), 카드 행, 타임라인 중 선택.
5. **각주**: y 7.13~7.45, 8~10pt, `*` 또는 `※`로 시작.

## 5. 작성 규칙
1. **리드 문장이 결론이다.** "임대차 현황"이 아니라 "WALE 6.8년으로 안정적 현금흐름 확보"처럼 쓴다. 16pt 한 문장 안에 수치를 넣는다.
2. **제목에 번호**를 단다 (`> 1.`, `> 2.`). 섹션 내에서 연속 번호.
3. **모든 수치에 출처 각주.** 데이터는 `00_원본자료/processed/`의 값만 쓰고 파일·버전을 각주에 적는다.
4. **표가 기본 표현 수단이다.** 3개 이상 항목 비교는 표로 만들고 머리행은 연한 블루 배경 + Bold.
5. **리스크는 표로**: 구분 | 리스크 | 대응방안. 좌측에 번호 사각형을 붙인다.
6. **수익 확약성 표현 금지** ("보장", "확정 수익"). "예상", "추정", "시나리오 기준"으로 쓴다.
7. **변동 가능 항목에는 단서**를 단다: `※ 상기 내용 중 일부는 협의 과정에서 변동될 수 있음.`
8. **일정은 기준 일정을 따른다** (`CLAUDE.md` 자동 작동 규칙 5).

## 7. 생성 방법
```bash
python3 platform/scripts/ic_deck.py --demo /tmp/sample.pptx   # 양식 확인용 샘플
```
실제 자료는 `platform/scripts/ic_deck.py`를 import 해 슬라이드를 구성한다. 사용 예시는 파일 하단 `_demo()` 참고.

생성 후 반드시 확인한다.
- `markitdown 결과물.pptx` 로 내용 누락·순서 확인
- 자리표시자 문구(`XXX`, `TODO`, `[insert`) 잔존 여부 확인
- 표가 슬라이드 하단 경계(7.44")를 넘지 않는지 확인
