# 법률 검토 체크리스트

## 매매계약(SPA)
- [ ] 매매대금·지급 일정·에스크로 조건
- [ ] 진술 및 보장(R&W) 범위, 존속기간, cap/basket
- [ ] 선행조건(CP) 목록과 충족 책임·기한
- [ ] 해제 사유, 위약금, 계약금 몰취
- [ ] 하자담보책임, 환경오염 책임 분담
- [ ] 임대차 승계, 보증금 반환 의무 이전
- [ ] 세금·비용 부담 (취득세, 부가세, 중개수수료)
- [ ] 준거법·관할·분쟁해결

## 임대차계약
- [ ] 기간, 갱신 옵션, 조기해지권과 위약금
- [ ] 임대료·관리비·인상률(CPI 연동), 렌트프리, TI
- [ ] 보증금 규모 및 반환 조건
- [ ] 원상회복, 전대·양도 제한
- [ ] 상가건물임대차보호법 적용 여부 (환산보증금)

## 대출약정
- [ ] LTV·DSCR 등 재무약정과 테스트 주기
- [ ] 기한이익상실(EOD) 사유, 치유 기간
- [ ] 조기상환수수료, 금리 조건
- [ ] 담보 범위, 현금관리계좌 구조(waterfall)
- [ ] 크로스디폴트, 양도·변경 제한

## 펀드·신탁·SPC
- [ ] 자본시장법상 인가·등록 요건, 이해상충
- [ ] 보수 구조, 투자자 동의 사항
- [ ] 청산·환매·만기 연장 조건

## 공통
- [ ] 등기부·토지대장·건축물대장 일치 여부
- [ ] 인허가·용도 제한, 위반건축물 여부
- [ ] 소송·가압류·유치권 등 권리 제한
- [ ] 외부 법무법인 확인 필요 사항 목록화
