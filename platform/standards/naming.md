# 파일·폴더 명명 규칙

## 프로젝트 코드명
- 영문 대문자·숫자·하이픈: `GNG-TOWER`, `PANGYO-LOG-01`
- 폴더: `projects/<코드명>/`

## 파일명
`YYYYMMDD_<유형>_<제목>_v##.<ext>`
- 예: `20260916_렌트롤_매도자제공_v01.xlsx`, `20260920_법률의견서_SPA초안_v02.md`
- 원본(raw)은 접수일 접두어만 붙이고 나머지는 원래 이름 유지 가능
- 같은 자료의 재접수·수정은 v를 올리고 이전 버전을 삭제하지 않음

## 유형 코드
렌트롤 / 감정평가 / 재무제표 / 실사물리 / 실사환경 / 실사법률 / 시장자료 / IM / 계약서 / 금융 / 법률의견서 / 협상조건 / 보고서 / 투심자료 / 발표스크립트 / 회의록 / QA / 아젠다 / 의사결정보고

## 마크다운 문서 공통 헤더
```
# <제목>
- 프로젝트: <코드명> / 작성일: YYYY-MM-DD / 작성: <에이전트명> / 버전: v##
- 근거 데이터: <00_원본자료/processed/...> (버전)
```
