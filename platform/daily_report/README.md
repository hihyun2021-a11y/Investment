# 상장리츠 공시·금리 일일 보고 메일

매일 아침 코스피 상장리츠 23개 종목의 공시와 주요 금리를 모아 HTML 메일로 보냅니다.
임영규 부장님 「[상장리츠 공시] 08:00 기준 새 공시」 메일 구성을 따르고, 맨 앞에 **금리 표**를 추가했습니다.

| 메일 구성 | 내용 | 출처 |
|---|---|---|
| 1. 주요 금리 | 국내: 기준금리, CD·CP(91일), 국고채 3·5·10년, 회사채 AA-·BBB-(3년) / 미국: 연방기금 실효금리, SOFR, 국채 2·10년 — 전일·1주 전 대비 bp | 한국은행 ECOS, FRED |
| 2. 리츠별 재무 지표 | 시가배당수익률(연환산)·가중평균 차입금리·LTV·NAV·P/NAV — 아래 「재무 지표」 참고 | OpenDART + 네이버증권 종가·시총 |
| 3. 주요사항 공시(최근 30일) | 자금차입(형태·금액·금리·기간), 유상증자(발행가액·규모), 유형자산 취득·처분 — 정정공시는 최신 1건 | 네이버증권(KOSCOM) |
| 4. 리츠별 공시 | 최근 5일 새 공시(리츠별 최신 1건), 종목별 최근 공시 4건 + 전일 종가·등락률·시가총액 | 네이버증권 |

외부 패키지 설치가 필요 없습니다(Python 3.9 이상만 있으면 됨).

## 처음 설정 (회사 PC, 10분)
1. **ECOS·FRED 인증키**: https://ecos.bok.or.kr 인증키 신청 / https://fred.stlouisfed.org → My Account → API Keys (둘 다 무료).
2. **Gmail 앱 비밀번호**: 보낼 Gmail 계정 → Google 계정 관리 → 보안 → 2단계 인증 켜기 → "앱 비밀번호" 16자리 생성.
3. 이 폴더의 `env.txt`(없으면 `env.example.txt`를 복사)를 메모장으로 열어 Gmail 정보와 받는 주소(`MAIL_TO`)를 채웁니다.
   - `.env` 확장자는 회사 PC에서 AnySign4PC(인증서 암호화 파일)와 연결돼 있어 더블클릭하면 암호 창이 뜹니다. 그래서 `env.txt`를 씁니다(`.env`도 계속 읽음).
4. `run_daily.bat`을 더블클릭하면 메뉴가 뜹니다. **1번 점검**부터 실행하세요.
   - 시세·공시 목록·공시 본문·금리·메일 설정이 차례로 나옵니다. 경고가 나오면 그 화면을 캡처해 Claude에게 주세요.
5. **2번 미리보기**: 브라우저에 오늘 메일 모양이 열립니다(발송 안 함). **3번**은 지금 바로 발송입니다.
6. **4번 자동 발송 등록**(또는 `register_task.bat`) → 평일 09:10 자동 발송. 자동 실행 기록은 `run.log`에 남습니다.
   - PC가 켜져 있어야 합니다. 해제: `schtasks /delete /tn ReitsDailyReport /f`
   - PC를 꺼 두고 받으려면 `github_actions_예시.yml` 안내대로 GitHub Actions를 쓸 수 있습니다.

## 발송 방식
- 기본은 Gmail(`MAIL_METHOD=gmail`). 회사 보안 프로그램이 외부 메일 서버를 막아 "Connection unexpectedly closed"가 나오면 `env.txt`에 `MAIL_METHOD=outlook`을 넣으세요. 회사 PC의 Outlook(로그인 상태)으로 보내며 Gmail 정보는 필요 없습니다.
- 앱 비밀번호의 띄어쓰기는 자동으로 지웁니다.

## 설정 바꾸기 (`config.json`)
- 종목 추가·삭제: `reits` 목록. `code`가 null이면 네이버 종목검색으로 자동으로 찾습니다(현재 대신밸류리츠).
- 금리 항목: `rates` (ECOS 통계코드 `817Y002` 시장금리 일별, `722Y001` 기준금리), `fred` (FRED 시리즈 ID: DFF·SOFR·DGS2·DGS10 등).
- 기간: `major_window_days`(주요사항, 기본 30일), `new_window_days`(새 공시, 기본 5일).

## 재무 지표 (OpenDART, `dart_metrics.py`)
`env.txt`에 `DART_API_KEY=`(opendart.fss.or.kr → 인증키 신청)를 넣으면 메일에 표가 추가됩니다. 메뉴 **6번**은 이 표만 계산해 화면에 보여 주고 근거 폴더를 엽니다.

| 지표 | 계산 |
|---|---|
| 시가배당수익률(연환산) | 가장 최근 「부동산투자회사금전배당결정」 공시(정정공시는 같은 배당기준일이면 최신 1건, '주주명부폐쇄(기준일)결정' 공시는 제외)의 보통주 1주당 배당금 × (12 ÷ 결산기간 개월) ÷ 전일 종가. 결산기간은 ① `dart_override`의 `settle_months` ② 공시의 배당대상기간 ③ 정기보고서 기간(사업보고서 간격, 사업↔반기 간격의 2배, 분기보고서 제출 시 12개월) ④ 배당기준일 간격 순으로 정하고, 배당이 결산보다 잦으면(분기배당) 배당기준일 간격을 씀. **회차당 8% 이상(특별·청산 배당 가능성)은 연환산하지 않고 '(회차)'로 표시** |
| 가중평균 차입금리 | 최근 사업·반기보고서 「재무제표 주석」(별도 기준)의 차입금·사채 표(XBRL 표준 주석)에서 차입처별 당기말 금액 × 이자율 가중평균. `기준이자율 CD + 조정 x%`나 `CD+가산금리` 변동금리는 그날 ECOS CD(91일)+가산금리로 계산하고 `[추정]` 표시 |
| LTV | 차입금·사채 당기말 장부금액 ÷ 자산가치. 차입금·사채 합계는 주석 장부금액 합계와 같은 숫자인 **재무상태표의 차입금·사채 과목 합계**로 확정하고, 주석 합계는 근거 파일에 대조용으로 남김. 자산가치 = 종속·관계기업투자 기말 장부금액(재무상태표) + 투자부동산 공정가치(주석의 공정가치 서열체계 표, 없으면 장부금액). 이 둘이 총자산의 절반에 못 미치고 수익증권 등 비유동 공정가치측정 금융자산이 주력인 리츠(예: NH프라임·마스턴프리미어)는 그 금액을 더하고 비고에 표시 |
| NAV · P/NAV | NAV = 위 자산가치 − 차입금·사채 − 재무상태표 임대보증금(장부금액, 별도 과목이 없으면 주석의 임대보증금 행). P/NAV = 네이버증권 시가총액(보통주) ÷ NAV |

- **별도재무제표 기준**이라 자리츠를 거쳐 투자하는 리츠(ESR켄달스퀘어·제이알글로벌·KB스타·대신밸류 등)는 자리츠의 차입금이 빠져 LTV가 낮게 보입니다. 연결 기준이 필요하면 말씀해 주세요.
- 2026-11-06 23개 리츠 실제 보고서(최신 사업·반기보고서, 배당결정 공시)로 검증했습니다. 차입금·사채 합계는 23개 모두 재무상태표와 일치합니다.
- 처음 실행 때 종목별 보고서 원문을 받아 `data/dart/`에 저장합니다(3~10분). 다음부터는 새 보고서·새 배당공시가 나온 종목만 받습니다.
- **계산 근거**: `data/dart_trace/<종목코드>_<종목명>.txt`에 어느 주석·어느 행(차입처·금액·이자율)을 썼는지 남습니다. 값이 이상하면 이 파일을 보내 주세요.
- **값 고치기**: 자동 추출이 틀린 종목은 `config.json` → `dart_override`에 종목명별로 `settle_months`, `debt_won`, `rate`, `ip_won`, `eq_won`, `deposit_won`(원 단위, rate는 %)을 넣으면 그 값을 씁니다. DART 회사를 못 찾으면 `dart_corp_code`(8자리 고유번호)를 넣습니다.
- 비고 칸에 `[추정]`·`… 미확인`·`주석 파싱 실패 → 재무상태표 과목` 같은 표시가 나오면 해당 값은 원문 확인이 필요합니다. 표 아래 각주처럼 자동 추출값이라 의사결정 자료에 쓰기 전 원문 대조가 필요합니다.
- 시가총액은 보통주 기준이라 종류주식이 있는 리츠는 P/NAV가 낮게 나올 수 있습니다.
- 코람코더원리츠처럼 자산을 매각한 리츠는 LTV·NAV를 '-'로 두고 비고에 표시합니다.

## 동작 방식·유의사항
- "직전 보고 이후 새 공시"(주황 글씨)는 `data/state.json`의 마지막 발송 시각 이후 공시입니다. 처음엔 하루 전 기준입니다.
- 자금차입 금리·금액 등은 공시 본문에서 자동으로 뽑습니다. 양식이 특이한 공시는 빈칸(-)이 될 수 있으니 링크로 확인하세요.
- 네이버증권 화면·API 구조가 바뀌면 수집이 깨질 수 있습니다. 메일 하단 "수집 경고"에 원인이 표시됩니다.
- 네이버증권 데이터는 KOSCOM 제공 정보입니다. 개인·팀 내부 참고용으로 쓰고, 외부 재배포는 하지 않습니다.
- `env.txt`·`.env`(키·비밀번호)와 `data/`는 깃에 올라가지 않습니다.
