# 상장리츠 공시·금리 일일 보고 메일

매일 아침 코스피 상장리츠 23개 종목의 공시와 주요 금리를 모아 HTML 메일로 보냅니다.
임영규 부장님 「[상장리츠 공시] 08:00 기준 새 공시」 메일 구성을 따르고, 맨 앞에 **금리 표**를 추가했습니다.

| 메일 구성 | 내용 | 출처 |
|---|---|---|
| 1. 주요 금리 | 국내: 기준금리, CD·CP(91일), 국고채 3·5·10년, 회사채 AA-·BBB-(3년) / 미국: 연방기금 실효금리, SOFR, 국채 2·10년 — 전일·1주 전 대비 bp | 한국은행 ECOS, FRED |
| 2. 주요사항 공시(최근 30일) | 자금차입(형태·금액·금리·기간), 유상증자(발행가액·규모), 유형자산 취득·처분 — 정정공시는 최신 1건 | 네이버증권(KOSCOM) |
| 3. 리츠별 공시 | 최근 5일 새 공시(리츠별 최신 1건), 종목별 최근 공시 4건 + 전일 종가·등락률·시가총액 | 네이버증권 |

외부 패키지 설치가 필요 없습니다(Python 3.9 이상만 있으면 됨).

## 처음 설정 (회사 PC, 10분)
1. **ECOS·FRED 인증키**: https://ecos.bok.or.kr 인증키 신청 / https://fred.stlouisfed.org → My Account → API Keys (둘 다 무료).
2. **Gmail 앱 비밀번호**: 보낼 Gmail 계정 → Google 계정 관리 → 보안 → 2단계 인증 켜기 → "앱 비밀번호" 16자리 생성.
3. 이 폴더의 `env.txt`(없으면 `env.example.txt`를 복사)를 메모장으로 열어 Gmail 정보와 받는 주소(`MAIL_TO`)를 채웁니다.
   - `.env` 확장자는 회사 PC에서 AnySign4PC(인증서 암호화 파일)와 연결돼 있어 더블클릭하면 암호 창이 뜹니다. 그래서 `env.txt`를 씁니다(`.env`도 계속 읽음).
4. `run_daily.bat`을 더블클릭하면 메뉴가 뜹니다. **1번 점검**부터 실행하세요.
   - 시세·공시 목록·공시 본문·금리·메일 설정이 차례로 나옵니다. 경고가 나오면 그 화면을 캡처해 Claude에게 주세요.
5. **2번 미리보기**: 브라우저에 오늘 메일 모양이 열립니다(발송 안 함). **3번**은 지금 바로 발송입니다.
6. **4번 자동 발송 등록**(또는 `register_task.bat`) → 평일 07:50 자동 발송. 자동 실행 기록은 `run.log`에 남습니다.
   - PC가 켜져 있어야 합니다. 해제: `schtasks /delete /tn ReitsDailyReport /f`
   - PC를 꺼 두고 받으려면 `github_actions_예시.yml` 안내대로 GitHub Actions를 쓸 수 있습니다.

## 설정 바꾸기 (`config.json`)
- 종목 추가·삭제: `reits` 목록. `code`가 null이면 네이버 종목검색으로 자동으로 찾습니다(현재 대신밸류리츠).
- 금리 항목: `rates` (ECOS 통계코드 `817Y002` 시장금리 일별, `722Y001` 기준금리), `fred` (FRED 시리즈 ID: DFF·SOFR·DGS2·DGS10 등).
- 기간: `major_window_days`(주요사항, 기본 30일), `new_window_days`(새 공시, 기본 5일).

## 동작 방식·유의사항
- "직전 보고 이후 새 공시"(주황 글씨)는 `data/state.json`의 마지막 발송 시각 이후 공시입니다. 처음엔 하루 전 기준입니다.
- 자금차입 금리·금액 등은 공시 본문에서 자동으로 뽑습니다. 양식이 특이한 공시는 빈칸(-)이 될 수 있으니 링크로 확인하세요.
- 네이버증권 화면·API 구조가 바뀌면 수집이 깨질 수 있습니다. 메일 하단 "수집 경고"에 원인이 표시됩니다.
- 네이버증권 데이터는 KOSCOM 제공 정보입니다. 개인·팀 내부 참고용으로 쓰고, 외부 재배포는 하지 않습니다.
- `env.txt`·`.env`(키·비밀번호)와 `data/`는 깃에 올라가지 않습니다.
