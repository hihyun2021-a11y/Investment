# 렌트롤 작성 실습 (Clean) — 2026-10-11 v01

`20261011_실습_렌트롤작성실습_강의용Clean_v01.xlsx` — 가상 물류센터(임대가능면적 28,000㎡, 12개 구획) 기준

| 시트 | 내용 |
|---|---|
| 0_안내 | 시트 구성, 작성 규칙, 주요 산식(임대율·WALE·보증금 배수·Effective Rent), 실습 과제 5개, 강사용 정답 |
| 1_RentRoll_예시 | 작성 예시. 노란 칸 = 입력, 연두 칸 = 수식(평 환산·잔여기간·보증금/임대료 총액·연 임대료·보증금 배수), 합계 행에 임대료 가중 WALE |
| 2_요약 | 임대율, WALE(임대료·면적 기준), 임차인별 비중(앵커 자동 표시), 연도별 만기 스케줄(30% 이상 강조), 보증금 담보 구분 |
| 3_실습_빈양식 | 수식이 들어간 빈 렌트롤 15행 |
| 4_실습_오류찾기 | 오류 4건이 들어간 렌트롤 + 검증 열(빈칸) |

- 임차인은 "임차인 A~H"로 표기했다. 면적·금액·일자는 모두 가상의 값이다.
- 기준일(각 시트 C3)을 바꾸면 잔여기간·WALE·만기 스케줄이 다시 계산된다.
- 배포할 때는 0_안내 시트의 "강사용 정답" 표를 지운다.
- 재생성 방법: `python3 build/build_rentroll_practice.py`
