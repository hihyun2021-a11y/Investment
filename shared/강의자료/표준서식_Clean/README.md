## 작성 원칙
- 실제 거래자료에서는 **문서의 일반적인 구성(조문 체계)만** 참고했다. 문안은 새로 썼고, 법무법인 초안 문구를 그대로 옮기지 않았다(저작권 고려).
- 매도인·매수인·자산명·소재지·투자자·대주·자문사·담당자명, 실제 금액·금리·일정은 넣지 않았다. 그런 값은 모두 `[●]`로 비워 두었다.
- 해당 거래에만 있는 특수 조항(특정 상계납입 구조, 개별 민원·광고물 조항 등)은 뺐다.
- 임대차계약서의 당사자·소재지·금액은 **가상의 예시값**이다: 5,000㎡ = 1,512.50평, 월 임대료는 평당 30,000원, 보증금은 10개월분.
- 문서 속성의 작성자·회사 정보는 비웠다. 머리말과 꼬리말에는 "강의용 예시, 법률 자문 아님" 문구가 들어 있다.
- 재생성 방법: `python3 build/build_all.py`

※ 교육용 일반 예시이며 법률 자문이 아니다. 실제 거래에 쓰려면 외부 법무법인의 검토가 필요하다.
