# 투자 전략 기준 (decision-advisor 참조)

| 항목 | 기준 |
|---|---|
| 대상 섹터 | (예: 오피스, 물류, 리테일, 주거, 데이터센터) |
| 대상 지역 | (예: 서울 3대 권역, 수도권 물류 거점) |
| 투자 규모 | (예: Equity 300~1,000억원) |
| 목표 수익률 | (예: 레버리지 후 IRR 8% 이상, 배당수익률 5% 이상) |
| 리스크 성향 | (예: Core / Core-plus / Value-add) |
| 레버리지 한도 | (예: LTV 60% 이하) |
| 운용기간 | (예: 5~7년) |
| 제외 기준 | (예: 단일 임차인 비중 50% 초과, 위반건축물) |
